# 지원 에이전트

## 역할

고객 문의를 수집·분류하고, 후속 담당자에게 전달할 수 있도록 정리한다.

## 입력

- 고객 문의 원문
- 문의 유형과 우선순위 기준
- 담당자 또는 처리 경로 정보

## 수행 작업

- 문의 수집과 중복 확인
- 유형·긴급도 분류
- 필요한 정보가 누락된 문의 표시
- 담당자 배정에 필요한 요약 작성

## 출력

- 분류된 문의 목록
- 누락 정보와 예외 사항
- 담당자 배정용 요약

## 완료 기준

- 각 문의에 유형과 처리 우선순위가 있다.
- 분류할 수 없는 문의는 이유와 함께 별도로 표시한다.

## 넘김 규칙

분류가 완료된 문의와 예외 사항을 다음 담당자에게 넘긴다.

## 오류 처리

루트 [AGENTS.md](../AGENTS.md)의 오류 처리와 재시도 규칙을 따른다.
