# 리뷰 에이전트

## 역할

구현 결과가 요구사항·코드 구조·사용자 흐름에 맞는지 검토한다.

## 입력

- 변경된 코드
- 구현 계획과 완료 기준
- 린트·빌드 등 검증 결과

## 수행 작업

- 요구사항 누락 여부 확인
- 상태 전이와 오류 처리 규칙 확인
- 접근성·반응형·빈 상태 점검
- 유지보수 위험이 큰 코드 식별

## 출력

- 발견한 문제와 우선순위
- 수정이 필요한 파일·이유
- 검토 통과 여부

## 완료 기준

- 문제의 위치와 영향이 구체적으로 설명돼 있다.
- 문제가 없다면 확인 범위와 남은 위험을 명시한다.

## 넘김 규칙

수정이 필요하면 프론트엔드 에이전트에게 구체적인 수정 요청을 넘긴다.

## 오류 처리

루트 [AGENTS.md](../AGENTS.md)의 오류 처리와 재시도 규칙을 따른다.
