# UI 수동 점검표

UI 또는 사용자 흐름을 변경했을 때 Verification Gate에서 실행한다. 현재 템플릿의 기준 라우트와 조작을 최소 범위로 확인하며, 변경 기능의 주요 성공·오류 상태를 추가한다. 새 테스트 라이브러리는 필요하지 않다.

## 준비

1. Node.js 24.15.0 이상에서 `pnpm dev --host 127.0.0.1`을 실행한다.
2. 브라우저, OS, 검사한 데스크톱·모바일 뷰포트 크기를 기록한다.
3. 개발자 콘솔의 오류 유무를 확인한다.

## 기본 화면과 조작

| 점검 | 기대 결과 |
| --- | --- |
| `/` 열기 | 홈 제목과 주요 링크가 표시된다. |
| `About` 링크 또는 `/about` 열기 | About 화면이 표시되고 홈으로 돌아갈 수 있다. |
| 존재하지 않는 경로 열기 | 404 안내가 표시되고 홈 링크로 복귀할 수 있다. |
| 모바일 폭(예: 375px)에서 위 화면 확인 | 콘텐츠가 잘리지 않고 가로 스크롤이 불필요하다. |
| 키보드 `Tab`·`Enter`로 탐색 | 링크·버튼에 접근할 수 있고 포커스가 보인다. |
| 변경한 기능의 성공·빈 상태·오류 상태 | 계획과 Design Gate에서 정의한 동작을 따른다. 해당 상태가 없다면 `해당 없음`을 기록한다. |

## 결과 기록

Handoff의 검증 근거에 각 점검의 `pass`·`fail`·`not-run`, 브라우저·뷰포트, 실패 재현 단계와 미실행 이유를 적는다. 화면이나 사용자 흐름을 바꾸지 않은 작업은 이 점검을 생략하고 `해당 없음`으로 기록한다. 수동 점검은 단위 테스트·타입 검사·빌드를 대체하지 않는다.
